# Operational excellence pillars

`gcp`

The operational excellence pillar is the group of AWS Well-Architected Framework principles for running systems and improving operations over time. The table below lists them.


| Principle | What it means |
|---|---|
| Perform operations as code | Limits human error, enables automation, improves response time to events |
| Make small, frequent, reversible changes | Don't overhaul your entire application in a couple of changes. Test changes on certain components so you can update them regularly. |
| Anticipate failure | When things break, analyze the cause and learn from it, write test code that is designed to break your architecture so you can test recovery. |
| Refine operational procedures frequently | Draw on past events to find continuous opportunities to improve your operations. |
