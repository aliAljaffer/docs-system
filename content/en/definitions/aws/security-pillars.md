# security pillars

`gcp`

The security pillar is the group of AWS Well-Architected Framework principles for protecting data, systems, and assets. This page lists them.

1. Implement a strong identity foundation
	1. [[principle-of-least-privilege|Principle of Least Privilege]]
2. Enable traceability
	1. [[logging]] and metric collections
3. Automate security best practices
	1. Utilize policies
4. Protect data in transit and at rest
	1. In transit: SSL/TLS
	2. Server/client encryption
5. Keep people away from data
6. Anticipate security events to automate recovery.
