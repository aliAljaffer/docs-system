# Appsync

`aws` `services`

real-time data sync using GraphQL for mobile and web apps, whether online or offline.

A service designed for mobile applications that require user
and data synchronization across multiple devices. AWS AppSync supports
iOS, Android, and JavaScript (React and Angular). Select data records can be
synchronized automatically across multiple devices using the GraphQL query
language.
