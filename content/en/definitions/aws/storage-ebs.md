# ebs

Elastic Block Storage - **Most useful for [[compute-ec2-ccp|ec2-ccp]] instances** as it can be directly access by the OS of the instance. Can be attached to multiple [[compute-ec2-ccp|ec2-ccp]] instances, but only one at a time.
## EBS Types
- SSD Based
- HDD Based
