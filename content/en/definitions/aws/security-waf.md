# waf

**AWS Web Application Firewall (WAF)**
- Application-level firewall that you can write rules to allow/deny traffic to your AWS resources.
- Attaches to either [[networking-cloudfront|cloudfront]] or App Load Balancer.
- Protects against the 10 most dangerous attacks, like SQL injection and Cross-Site-Scripting (XSS).
