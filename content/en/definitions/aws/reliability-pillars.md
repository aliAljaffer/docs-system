# reliability pillars

`gcp`

The reliability pillar is the group of AWS Well-Architected Framework principles for helping a workload recover from failure and meet demand. The table below lists them.


| Principle | What it means |
|---|---|
| Automatically recover from failure | Monitor KPI and trigger automation when threshold is breached |
| Test recovery procedures | Don't assume your procedures will work |
| Scale horizontally to increase availability | Replace one large resource with multiple resources to reduce the impact of a single failure |
| Stop guessing capacity | Utilize cloud flexibility to right size your resources |
| Manage changes via automation | Use [[infrastructure-as-code|IaC]] |
