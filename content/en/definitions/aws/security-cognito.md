# Cognito

`aws` `services`

A sign-in service that allows users to use social media accounts (Google, Facebook, Apple, etc) to log-in. It manages the identities by having user groups and identity pools.
## User Groups
A directory of users
## Identity Pools
Allows you to give temporary credentials to a 3rd party verified user to access AWS services.
