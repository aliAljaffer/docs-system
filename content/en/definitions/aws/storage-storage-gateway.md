# storage gateway

`aws` `services`

Provide on-premise apps with access to virtually unlimited cloud storage.

- **Tape Gateway** - Transfer data from physical tapes
- **[[storage-s3|S3]] File Gateway** - Provides SMB or NFS based access to data in [[storage-s3|s3]]
- **Volume Gateway** - Presents iSCSI block storage volumes to your on-premise apps that you can either store in [[storage-s3|s3]] or migrate to [[storage-ebs|ebs]]
