# Config

`aws` `services`

**AWS Config is a service used to manage changes in your AWS account and make sure they are compliant with processes set by the organization.**
Config is [[region]] specific.
Use cases:
- Ensure a resource stays configured in a specific way
- Keep track of all configuration changes to resources
- Lists all resources within a [[region]]
- Assist with security analysis by detailing historical information and changes.
