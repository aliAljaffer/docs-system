# application migration service

`aws` `services`

MGN - Move and improve your on-premises and cloud-based applications. **Can migrate between AWS [[region|regions]]!!!!!!**

| Benefit | Description |
|---|---|
| Migrate applications | Migrate applications from any source infrastructure that runs supported operating systems. |
| Modernize applications during migration | Modernize your applications during migration with options such as disaster recovery and operating system or license conversion. |
| Maintain normal business operations | Maintain normal business operations throughout the application replication process. |
| Reduce costs | Reduce costs by using one tool for a wide range of applications, with no need to invest in application-specific skills. |
