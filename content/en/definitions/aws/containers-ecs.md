# Ecs

`aws` `services`

**Amazon Elastic Container Service (Amazon ECS)** is a fully managed [[containers]] orchestration service that helps you to more efficiently deploy, manage, and scale containerized applications. It deeply integrates with the AWS environment to provide an easy-to-use solution for running container workloads in the cloud and on premises with advanced security features using Amazon ECS Anywhere. 
- Scalable
- Pay-as-you-go
- Increase in speed and agility
- Optimizes compliance and security
## How it works
Simply describe your application and the resources required and [[containers-ecs|ecs]] will launch, monitor, and scale your application across flexible compute options with automatic [[application-integration|integrations]] to other supporting AWS services that your application needs. Perform system operations such as creating custom [[scalability|scaling]] and capacity rules, and observe and query data from application logs and telemetry.
[source](https://aws.amazon.com/ecs/)
