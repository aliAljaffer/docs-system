# Performance efficiency pillar

`gcp`

The performance efficiency pillar is the group of AWS Well-Architected Framework principles for using computing resources efficiently to meet requirements. This page lists them.

- Democratizing advanced technology
- Go global
	- Deploying workloads to multiple AWS [[region|regions]] which lowers latency
- Utilize [[serverless]] architecture
- Experiment often
