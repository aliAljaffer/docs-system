# Cloud computing

`cloud` `fundamentals`

cloud computing is the practice of using a network of remote servers hosted on the internet to store, manage, and process data, rather than a local server or a personal computer.

"Cloud computing is the on-demand delivery of IT resources over the internet with pay-as-you-go pricing." [source](https://youtu.be/JsmhEgIV1mQ?t=671)
