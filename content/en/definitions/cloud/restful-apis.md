# restful apis

A RESTful API is a web interface that follows the REST (Representational State Transfer) style. Clients send standard HTTP requests to access and change resources.

## [What is RESTful API?](https://aws.amazon.com/what-is/restful-api/)

Build RESTful APIs optimized for [[serverless]] workloads and HTTP backends using HTTP APIs. [HTTP APIs](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api.html) are the best choice for building APIs that only require API proxy functionality. If your APIs require API proxy functionality and API management features in a single solution, [[networking-api-gateway|API Gateway]] also offers [REST APIs](https://docs.aws.amazon.com/apigateway/latest/developerguide/http-api-vs-rest.html).
