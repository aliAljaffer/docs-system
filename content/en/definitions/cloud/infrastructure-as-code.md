# infrastructure as code

`cloud` `fundamentals` `iac`

IaC: Writing the configurations for a specific cloud infrastructure as code, rather than manually creating the infrastructure using the AWS UI for example.

Allow for less human-error, while also making the infrastructure share-able.

"Infrastructure as code (IaC) is the ability to provision and support your computing infrastructure using code instead of manual processes and settings. Any application environment requires many infrastructure components like operating systems, database connections, and storage. Developers have to regularly set up, update, and maintain the infrastructure to develop, test, and deploy applications. 

Manual infrastructure management is time-consuming and prone to error - especially when you manage applications at scale. Infrastructure as code lets you define your infrastructure's desired state without including all the steps to get to that state. It automates infrastructure management so developers can focus on building and improving applications instead of managing environments. [[management-and-governance-organizations|Organizations]] use infrastructure as code to control costs, reduce risks, and respond with speed to new business opportunities." [What is Infrastructure as Code?](https://aws.amazon.com/what-is/iac/)
