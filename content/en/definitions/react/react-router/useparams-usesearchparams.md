# useParams-useSearchParams

- `useParams()`: Grabs the params in the URL after `/` i.e. it grabs 5 from `./games/acheivements/5`. Returns the value.

- `useSearchParams()`: Grabs named params in the URL query as a dictionary. `?q=4&z=0`. Returns state and setter.
