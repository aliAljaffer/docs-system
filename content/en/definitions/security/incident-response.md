# Incident response

Incident response (IR) is how an organization reacts to an attack.

1. **Preparation.** Plan and prepare a protocol for incidents.
2. **Identification.** The security team detects the security event. See [[attack-detection]].
3. **Containment.**
4. **Eradication.**
5. **Recovery.**
6. **Reflection.**
