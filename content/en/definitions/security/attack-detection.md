# Attack detection

Prevention cannot stop every attack. Detection finds the rest.

- Antimalware software.
- [[logging|Logging]].
- Network monitoring.
- [[traffic-analysis|Traffic analysis]].
- Security information and event management (SIEM) tools.
- Security operations center (SOC). The main challenge is to reduce false positives.
