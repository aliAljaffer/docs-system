# AWS Solutions Architect Associate (SAA-C03) Course

This course shares core AWS knowledge for the Solutions Architect - Associate certification, exam code SAA-C03. It covers key services and the comparisons that matter. It is not exhaustive.

## Study approach

1. Read the lessons in order. Later lessons build on earlier ones.
2. Study the comparison tables. Many exam questions ask which of two services fits.
3. Answer the exam tips at the end of each lesson from memory, then check.
4. Review lesson 12 last.
