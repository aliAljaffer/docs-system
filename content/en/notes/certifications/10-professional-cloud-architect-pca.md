## GCP for AWS Professionals
- AWS offers opt-in saving plans, GCP grants the discount automatically if VMs run for more than 25% of the month
- AWS [[security-iam|IAM]] Roles = GCP Service Accounts
- Some of the naming in GCP is very similar to K8s which is understandable (service accounts, user/role pairings)
- GCP Hierarchy: Org Node -> Folder -> Project -> Resource
- [[vpc|VPCs]] are global! And subnets can live in multiple Zones!
- Tag-based firewall rules
- Cross-region loadbalancing
