## Incident Response (IR)
1. Phase 1: Preparation. An organization plans and prepares a protocol on what it will do when an incident occurs.
2. Phase 2: Identification. The security team detects the security event.
3. Phase 3: Containment.
4. Phase 4: Eradication.
5. Phase 5: Recovery.
6. Phase 6: Reflection.
