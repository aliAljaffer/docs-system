# Fai

**Status:** Active

Fai is a self-hosted task tracker, Kanban board, and notes app. It runs as a web app behind your own identity provider, as a Docker Compose stack, or as a desktop app.

The data stays yours, and nobody else needs an account.

## What it does

- Tasks, notes, reminders, and calendar in one place.
- Web app behind an identity provider.
- Docker Compose deployment.
- Desktop app.
