# CKAD course

This course covers the Certified Kubernetes Application Developer (CKAD) study notes. Read the lessons in order.

Background: [[containers]] and [[vms-and-containers]].

The study notes do not describe the exam format. Check the official CKAD exam page for the format. Lesson 9 adds practical exam tips. For more, see the [Kubestronaut write-up](https://alialjaffer.com/case-study/k8s-adventures-pt2/).

| Lesson | Topics |
|---|---|
| [1. Pods](01-pods.md) | Read pod YAML and the `pod.spec` layout |
| [2. Configuration](02-configuration.md) | ConfigMaps and Secrets |
| [3. Multi-container pods](03-multi-container-pods.md) | Init containers and sidecars |
| [4. Labels and deployments](04-labels-and-deployments.md) | Labels, annotations, scaling, rollouts |
| [5. Workload types](05-workload-types.md) | Jobs, StatefulSets, DaemonSets, autoscaling |
| [6. Services](06-services.md) | Service types, creation, DNS |
| [7. Ingress and network policies](07-ingress-and-network-policies.md) | Ingress, Gateway API, NetworkPolicy, Istio |
| [8. Storage](08-storage.md) | Pod volumes and mounts |
| [9. Exam tips and tools](09-exam-tips-and-tools.md) | Exam environment, speed habits, documentation, practice |
| [10. Exam-day checklist](10-exam-day-checklist.md) | Review of the course tasks |
