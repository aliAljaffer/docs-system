# Fault tolerance

`cloud` `fundamentals` `reliability`

The ability to ensure there is no single point of failure and handle demand appropriately if there is a failure somewhere.

Primarily utilizes failover strategies, for example having a secondary copy of your DB ready to start using if your primary one in a diff. [[region]] fails.
