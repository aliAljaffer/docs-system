# Red Hat Certified System Administrator (RHCSA)

!!! warning "Unfinished"
    This course is a work in progress. The source notes do not yet cover software, systemd, storage and LVM, SELinux, the firewall, scheduling, or an exam overview.

This course covers the RHCSA topics from my study notes. It is not exhaustive.

Red Hat Enterprise Linux (RHEL) has a 10-year lifecycle. The notes list ext3, ext4, and xfs as Linux filesystems.

## Lessons

Study the lessons in order. Each lesson builds on the one before it.

| # | Lesson | Covers |
|---|--------|--------|
| 1 | [Linux Basics](01-linux-basics.md) | Root directories, mounting devices |
| 2 | [Shell and Text Tools](02-shell-and-text.md) | Help, shortcuts, history, redirects, pipes, grep, sed, awk |
| 3 | [Files, Links, and Archives](03-files-links-archives.md) | Copy, find, hard and soft links, tar |
| 4 | [Users and Groups](04-users-and-groups.md) | Accounts, groups, password files, sudo, startup files |
| 5 | [Permissions and Ownership](05-permissions-and-ownership.md) | chown, chmod, umask, shared group directories |
| 6 | [Networking](06-networking.md) | Interface names, hostnames, name resolution, ip |
