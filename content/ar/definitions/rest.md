# REST

REST هو أسلوب لتصميم واجهات البرمجة. يسمي العميل المورد، ويحدد فعل HTTP العملية.

| الطريقة | العملية |
|---|---|
| GET | قراءة |
| POST | إنشاء |
| PATCH | تحديث جزء من المورد |
| DELETE | حذف |

واجهة REST تسمي الموارد، لا الأفعال. `DELETE /api/tasks/7` يحذف المورد عند `/api/tasks/7`. لا يحتوي المسار على فعل.
