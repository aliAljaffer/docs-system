# رمز الحالة

رمز الحالة هو أول حقيقة يقرأها العميل من الاستجابة. يحدد ما حدث قبل أن يحلل العميل الجسم.

| الرمز | المعنى |
|---|---|
| 200 | نجح الطلب |
| 201 | تم إنشاء مورد |
| 400 | أرسل العميل بيانات غير صالحة |
| 404 | المورد غير موجود |
| 500 | فشل الخادم |

رمز الحالة جزء من عقد الواجهة. المورد المفقود يعيد 404، لا 200.
